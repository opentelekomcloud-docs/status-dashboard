API Overview
============

Status Dashboard APIs allow you to use all Status Dashboard functions.

.. _en-sd_topic_0000000002__table1:

.. table:: **Table 1** Status Dashboard APIs

   +--------------+--------------+----------------------------------------------------------------------------------------------------------------------------------+
   |Category      |Subcategory   |Description                                                                                                                       |
   +==============+==============+==================================================================================================================================+
   |Component     |Component     |Used to manage components, including the APIs used to query and update components.                                                |
   +--------------+--------------+----------------------------------------------------------------------------------------------------------------------------------+
   |Event         |Event         |Used to manage events, including the APIs used to query with pagination, create, update, extract events, and update event updates.|
   +--------------+--------------+----------------------------------------------------------------------------------------------------------------------------------+
   |Availability  |Availability  |Used to query availability data for components.                                                                                   |
   +--------------+--------------+----------------------------------------------------------------------------------------------------------------------------------+
